# Sirajan Muneera App

A modern, peaceful, and accessible mobile web application prototype for Sirajan Muneera prayers, events, community services, Qibla compass, Tasbeeh counter, daily Duas, and Islamic life. Built with React 19, TypeScript, Vite, and Tailwind CSS v4.

---

## 🚀 Overview

This repository provides a **UI-only prototype** for **Sirajan Muneera App**:
- All layouts, cards, navigations, spacing, typography, and responsive styles preserved.
- Backend and database connections (e.g. Supabase, external APIs) are decoupled into local mock stores.
- Static placeholder content rendered seamlessly across all screens.
- Completely client-side and functional out of the box.

---

## 🛠️ Development & Build

```bash
# Run local development server (port 3000)
npm run dev

# Compile and build production bundle
npm run build

# Preview build
npm run preview
```
