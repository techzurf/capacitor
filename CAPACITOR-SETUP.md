# Sirajan Muneera — Capacitor setup

This project has been prepared for Capacitor Android packaging. The existing React + TypeScript + Vite UI is preserved. The app is still a UI prototype using mock/in-memory data; this setup does not add a database.

## Requirements
- Node.js LTS (Node 20 or newer recommended for this Capacitor 7 setup)
- Android build environment: Android Studio + Android SDK, or a compatible cloud build provider

## Prepare the project
Run these commands from this folder:

```bash
npm install
npm run build
npx cap add android
npx cap sync android
```

The `android` folder is generated by `npx cap add android`; it is not included in this ZIP yet.

## Open/build Android locally
If Android Studio is installed:

```bash
npx cap open android
```

In Android Studio, let Gradle sync finish. Then use Build > Build Bundle(s) / APK(s) to create an APK or Android App Bundle (AAB).

## Important notes
- `appId` is currently `com.sirajanmuneera.app`. Change it before publishing if you prefer a different permanent application ID.
- The app's current data is mock/in-memory data. Changes may reset when the app restarts; Capacitor does not create a database.
- External API and map features require internet access and should be tested on a real Android device.
- Keep signing keys and credentials private. Do not upload them in public repositories or chats.
